## Why

Это первый урок вводного курса по диффузионным моделям (в стиле Stanford CS236 / CME296). Цель урока — соединить строгий математический вывод DDPM (прямой процесс, ELBO, репараметризация через шум, сведение KL к простой L2-потере) с осязаемым практическим опытом: обучить свою диффузионную модель на MNIST и посмотреть, как чистый шум шаг за шагом превращается в узнаваемые цифры.

Теория уже написана (`11-diffusion-models.md` из `ml_interview_cheat_sheet`), но без кода она остаётся абстрактной. Лабораторная работа нужна, чтобы студент прошел весь цикл — forward/noise schedule, обучение ε_θ, стохастический DDPM-сэмплер и детерминированный DDIM — и увидел, как каждая формула из теории превращается в строчку кода. Курс ориентирован на обучение, а не на SOTA, поэтому приоритет — читаемость, модульность и соответствие формулам урока, а не максимальное качество генерации.

## What Changes

- **Создать структуру курса** `lessons/NN-name-dd-something/` с подпапками `theory.md` + `lab/` для каждого урока (нумерация + слаг, как в Stanford CS236: `01-...`, `02-...`).
- **Скопировать теорию урока 1** из `ml_interview_cheat_sheet/11-diffusion-models.md` в `lessons/01-ddpm-from-scratch/theory.md` (без правок содержания — это source of truth теории).
- **Реализовать лабораторную работу** в `lessons/01-ddpm-from-scratch/lab/` — обучаемый DDPM на MNIST:
  - **DDPM-ядро** точно по формулам урока: linear noise schedule (β 1e-4→0.02), precomputed `α / ᾱ / √ᾱ / √(1-ᾱ)`, forward `x_t = √ᾱ·x₀ + √(1-ᾱ)·ε`, loss `‖ε − ε_θ(x_t,t)‖²`.
  - **Две архитектуры ε_θ** на выбор через конфиг: простой MLP с time-embedding (для прозрачности) и маленький U-Net с time-embedding (качественнее).
  - **Два сэмплера** из теории: стохастический DDPM (раздел 17) и детерминированный DDIM (раздел 18) для быстрой визуализации.
  - **Сквозной пайплайн** на PyTorch Lightning: скачивание MNIST → обучение → валидация → тест → артефакты.
  - **Конфиг гиперпараметров** (YAML/TOML): T, β-range, архитектура, batch size, lr, число эпох, частота сэмплинга и т.д.
  - **TensorBoard-логирование**: train/val loss, loss по интервалам t (SNR-взвешенный вид), метрики coverage/mode-collapse, тестовый инференс с визуализацией сгенерированных картинок на каждой эпохе.
  - **Метрики валидации** помимо MSE: loss в разрезе по basket'ам t (видно, как модель учится на слабом vs сильном шуме), coverage/mode-collapse через NN в пространстве фич (простой proxy разнообразия без тяжёлых метрик).
  - **Запускаемый скрипт** `train.py` (+ `sample.py` для генерации из чекпойнта) с CLI-аргументами и понятным README.
- **Менеджер пакетов — uv** (`pyproject.toml` + `uv.lock`), все зависимости фиксируются.

## Capabilities

### New Capabilities
- `course-structure`: организация курса `lessons/<NN-slug>/` с теорией и лабами, конвенции именования и структуры каталогов.
- `lesson-01-theory`: теория урока 1 — полный вывод DDPM (forward process, ELBO, репараметризация, сведение к L2), скопированная из `ml_interview_cheat_sheet`.
- `ddpm-core`: ядро DDPM точно по формулам теории — noise schedule, forward process, параметризация, loss-функция. Каркас, независимый от архитектуры сети.
- `noise-prediction-models`: две реализации ε_θ(x_t, t) — MLP и U-Net — с time-embedding, выбираемые через конфиг.
- `ddpm-samplers`: сэмплеры генерации — стохастический DDPM (раздел 17) и детерминированный DDIM (раздел 18) с настраиваемым числом шагов.
- `mnist-data`: загрузка/подготовка MNIST (скачивание, нормализация, даталоадеры train/val/test) с кешированием.
- `training-pipeline`: сквозной пайплайн на PyTorch Lightning — цикл обучения, валидация, чекпойнты, callbacks.
- `evaluation-metrics`: метрики качества генерации — loss по интервалам t, coverage и mode-collapse через NN в пространстве фич.
- `tensorboard-logging`: логирование в TensorBoard — скаляры (loss/metrics), тестовый инференс с визуализацией картинок на каждой эпохе, сравнение DDPM vs DDIM.
- `lab-config`: конфиг гиперпараметров лабы (T, β-range, архитектура, lr, batch, эпохи) с дефолтами и CLI-override.
- `lab-entrypoints`: запускаемые скрипты `train.py` и `sample.py` + README с инструкцией запуска.

## Impact

- **Новые файлы/каталоги**: `lessons/01-ddpm-from-scratch/{theory.md, lab/}`; в `lab/` — `pyproject.toml`, `uv.lock`, `configs/`, `src/` (модули), `scripts/` (`train.py`, `sample.py`), `README.md`.
- **Зависимости**: `torch`, `lightning` (PyTorch Lightning), `tensorboard`, `torchvision` (MNIST + Inception-фичи при необходимости), `numpy`, `tqdm`, `pyyaml`/`omegaconf` для конфига. Версии фиксируются через `uv.lock`.
- **Окружение**: целевая GPU = 6GB VRAM (ноут). Дефолтные гиперпараметры подбираются так, чтобы batch/T/архитектура влезали в 6GB; MNIST + маленький U-Net этому соответствует. CPU-фолбэк должен работать, но медленно.
- **Внешняя зависимость**: MNIST скачивается через `torchvision.datasets` (автоматически при первом запуске).
- **Не затрагивается**: `openspec/` (спеки), `AGENTS.md`, другие уроки (их пока нет).
- **Ограничения/некомпозитность**: это учебная реализация — без распределённого обучения, без mixed-precision как requirement (опционально), без сэмплинга в реальном времени. FID/IS осознанно не включены (Inception на MNIST ненадёжен и тяжеловатен для учебы).
